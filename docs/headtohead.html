How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one for an enterprise IT team evaluating data center colocation and managed services, TierPoint or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total).
  • Open comparison question: "TierPoint vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the reasoning notes above come from. It is not repeated, so a single odd answer could be noise.
  • Route, disclosed: all 72 runs (60 forced-pick + 12 open) came from the OpenAI API (gpt-4o), not the ChatGPT web app — the web app's anonymous-usage cap was still blocking this session when TierPoint's research started. Same question text, no memory or personalization either way, but no browsing on the API route, so nothing below carries a citation.
  • TierPoint doesn't win a single matchup outright. It loses cleanly and consistently (both name orders) to Equinix, Digital Realty, Flexential and Rackspace Technology — the three biggest global/scale players plus the multi-cloud specialist. Against CoreSite and Expedient, the overall score is an exact 5–5 tie, but that's not a real split decision: both come down entirely to which brand the question names first. Expedient is a complete flip (5 of 5 for TierPoint named first, 0 of 5 named second); CoreSite leans the same way but less completely (4 of 5 vs. 1 of 5).
  • Not yet covered: pricing, SLAs, specific facility counts and uptime guarantees as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any run on the ChatGPT web app for this project, or any engine besides GPT-4o.
